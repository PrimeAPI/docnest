# Security policy

DocNest is built to store sensitive documents, so we take security reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting
("Security" tab → "Report a vulnerability") on https://github.com/primeapi/docnest.

Include steps to reproduce, the affected version and the impact you see. You will get an
acknowledgement within a few days. Please give us a reasonable time to release a fix before
disclosing publicly.

## Supported versions

Only the latest release receives security fixes.

## Design

The security model and its limits are documented in [docs/security.md](docs/security.md).
